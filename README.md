# The Willowbrook Mysteries

A continuously-generated cosy English village mystery series, in the same
family as [neverending-story-reader](https://github.com/pauluk/neverending-story-reader)
but a distinct genre: gentle Agatha-Christie-flavoured whodunits set in the
fictional village of Willowbrook-on-Fen, starring a retired detective, a
nosy vicar, and the tearoom owner who hears everything.

Each chapter is loosely inspired by a real (deliberately light-hearted)
headline, fictionalised completely — see `scripts/generate_chapter.py`.

Read it at [`public/index.html`](public/index.html).
